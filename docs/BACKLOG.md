# 앞으로 구현할 요소

2026년 10월 10일(Unity 19일차까지) 기준으로, 앞으로 넣어야 하거나 넣으면 좋을 구현 요소를 모은 문서입니다. 순서와 끝난 기준은 [`ROADMAP.md`](ROADMAP.md)가, 화면은 [`PAGES.md`](PAGES.md)가 맡고, 이 문서는 "무엇이 남았는가"를 빠짐없이 적는 데 씁니다.

표의 구분은 다음과 같습니다.

| 구분 | 뜻 |
| --- | --- |
| 필수 | 없으면 그 단계의 끝난 기준을 넘지 못합니다 |
| 권장 | 없어도 단계는 끝나지만, 있으면 눈에 띄게 좋아집니다 |
| 선택 | 여유가 있을 때 넣습니다 |
| 결정 필요 | 사용자가 정해야 만들 수 있습니다(5절) |

단계는 `ROADMAP.md` 3절의 단계(0, 1-A~1-E)입니다. "1인, 주 10시간 이하" 조건에서는 필수만으로도 1단계가 7~9개월로 잡혀 있으므로, 권장과 선택은 필수를 밀어내지 않을 때만 넣습니다.

## 1. 지금 있는 것

- 걷기·달리기·점프, 1인칭과 3인칭, 블록 캐릭터와 이름표
- 늘 보이는 화면(메뉴 단추, 방 정보, 사람들 목록, 부품 칸)과 Esc 메뉴(바로가기·사람들·설정·도움말)
- 블록 여섯 색을 모눈에 놓고 지우기, 놓일 자리 미리 보기, 블록 수 표시
- 개인 설정 저장(마우스 감도, 시야각, 사람들 목록 표시)
- 맵 데이터 형식 1판(`MAP-FORMAT.md`)과 이 기기의 맵 파일 하나에 자동 저장·불러오기, 화면의 저장 표시
- 놓기·지우기·칠하기의 되돌리기(Ctrl+Z)와 다시 실행(Ctrl+Y), 최근 100번까지. 뒤의 도구도 같은 기록 층(`EditHistory`)을 씀
- 블록 칠하기(가운데 단추 또는 F), 화면 위 가운데의 알림 띠(놓을 수 없는 까닭, 저장 실패, 읽지 못한 블록 수, 되돌릴 것 없음)
- 날기(V): 중력 없이 Space로 오르고 Shift로 내려오며 높은 곳을 만듦. 끄면 떨어져 걸어 봄
- Windows 실행 파일을 만드는 명령줄 스크립트(`scripts/build-windows.mjs`)와 자동 실행 확인, 메뉴의 버전 표시
- 캐릭터를 몸(`CharacterMotor`)·카메라 리그(`ViewRig`)·PC 조작(`DesktopPlayerController`)으로 나눔. 몸은 조작 없이도 정해 준 방향으로 움직임
- VR 조작과 추적 리그: 머리와 두 손의 추적, 스틱으로 걷기와 끊어서 돌기, 점프와 날기, 몸이 머리를 따라오기. 가상 기기로 확인함
- OpenXR 연결: 실행할 때 `-vr`(또는 실행 파일 옆의 `AtelierVerse-VR.bat`)을 주었을 때만 VR 화면을 켜고, 기기가 없으면 키보드·마우스로 돌아와 까닭을 알림. 그냥 실행하면 VR 프로그램을 찾지 않음. **실제 헤드셋으로는 확인하지 못함**
- VR 메뉴: VR에서 화면을 눈앞에 떠 있는 판으로 띄움. 왼손의 메뉴 단추로 열고 오른손 광선과 방아쇠로 누름. 평소에는 알림만 보임. 화면과 도구는 조작 방식을 직접 알지 않고 이 기기의 캐릭터(`LocalPlayer`)를 거침. **가상 기기로만 확인함**
- VR에서 만들기: 오른손 광선으로 가리켜 방아쇠로 놓고, 옆 단추로 지우고, 왼손 방아쇠로 칠함. 왼손 위에 뜨는 부품 판에서 부품을 고르고 되돌리고 다시 실행함. 블록 놓기는 PC와 VR이 같은 코드를 씀. **가상 기기로만 확인함**
- 자유 배치: 블록은 칸에 맞추지 않고 가리킨 면 위의 그 자리에 놓이며 서로 겹쳐도 됨. 블록은 고유 번호와 자리(소수 좌표)로 기록함. 길이의 표준은 블록 한 변 = 1. 맵 형식 2판(1판 파일은 사본을 남기고 올려 읽음)
- 돌리기·옮기기·맞추기 도우미: 놓을 블록을 좌우로 15도씩 돌리고(R·T), 놓인 블록을 잡아 옮기고(G, 되돌리기 한 번에 돌아옴), 맞추기 도우미(C, 끈 것이 기본)를 켜면 모눈과 가리킨 블록에 맞춰 놓임. VR에서는 왼손 첫째 단추와 오른쪽 스틱 누르기로 돌리고, 왼손 옆 단추로 잡고, 부품 판의 단추로 맞추기를 바꿈. **VR은 가상 기기로만 확인함**
- 모양이 다른 부품과 부품 고르는 창: 판·기둥·경사·계단을 색마다 놓음(크기는 블록 한 변 1 기준, 부품마다 정해져 있음). 경사와 계단은 걸어 오름. 부품 고르는 창(B, VR은 부품 판의 단추)에서 부품 칸에 넣고 빼며 배치는 이 기기에 저장됨. 칠하기는 색만 바꾸고 모양은 그대로 둠. **VR은 가상 기기로만 확인함**
- 여러 맵 다루기: 이 기기에 맵을 여러 개 두고 맵 목록 창(M, 메뉴의 "내 작업실")에서 새 맵·열기·이름 바꾸기·지우기를 함. 새 맵은 빈 바닥으로 시작하고, 지운 맵은 휴지통 폴더로 옮겨지며, 다시 켜면 마지막으로 연 맵이 열림. VR에서는 이름을 바꿀 수 없음. **VR은 가상 기기로만 확인함. 글자판으로 한글 이름을 치는 것은 확인하지 못함**
- 시작 위치와 맵 정보: 맵마다 캐릭터가 처음 서는 자리와 방향을 정하고(지금 선 자리를 단추로, 바닥에 표식), 맵 정보 창에서 이름·설명을 고치고 지금 보는 장면을 대표 그림으로 찍음. 맵 목록의 줄에 작은 그림과 설명이 보임. 시작 위치가 블록에 막혀 있으면 그 위에 섬. 맵 형식 3판(2판 파일은 사본을 남기고 올려 읽음). VR에서는 설명을 쓸 수 없음. **VR은 가상 기기로만 확인함**
- 기본 소리: 걷기·뛰기·내려앉기, 블록 놓기·지우기·칠하기·옮기기·돌리기·잡기, 되돌리기, 단추와 창, 경고와 오류 알림, 대표 그림 찍기의 소리 22가지. 소리 파일 없이 코드로 만듦. 블록과 발의 소리는 그 자리에서 나고, 화면의 소리는 한 번에 하나만 남. 설정에 소리 크기(처음 값 70%). 소리 미리 듣기 파일을 내보내는 에디터 도구. **소리를 귀로 들어 보지 못함. VR은 가상 기기로만 확인함**

혼자서, PC에서, 맵 여러 개를 이 기기에만 저장하며 쓰는 상태입니다. 계정·여러 사람이 없고, VR은 걷기·메뉴·만들기까지 만들었지만 실제 헤드셋으로 확인하지 못했습니다. 소리는 넣었지만 귀로 들어 보지 못했습니다.

## 2. 가장 먼저 할 것

다음 일차의 후보를 순서대로 적습니다. 위에서부터 하나씩 일차로 삼습니다.

1. **실제 기기에서 확인한 결과 고치기**(3.4): 10~18일차의 VR 기능(조작, OpenXR 연결, 메뉴, 만들기, 돌리기·옮기기, 부품 고르는 창, 맵 목록과 맵 정보)을 헤드셋으로 켜 보지 못했습니다. 사용자가 Quest Link나 SteamVR을 설치하고 `AtelierVerse-VR.bat`으로 켜 본 결과가 오면 그것부터 고칩니다. 결과가 없으면 2번으로 갑니다.
2. **소리를 들어 본 결과 고치기**(3.10): 19일차의 소리는 숫자로만 정했습니다. 사용자가 `unity/Devlogs/Day19/sounds-preview.wav`나 실행 파일로 들어 보고 거슬리는 소리, 크기가 어울리지 않는 소리를 알려 주면 그것부터 고칩니다. 결과가 없으면 3번으로 갑니다.
3. **설정 늘리기**(3.9): 창과 전체 화면, 화면 품질, 마우스 위아래 뒤집기. 빌드에서 창 크기를 바꿀 수 있게 된 뒤의 다음 단계입니다. 소리 크기는 19일차에 넣었습니다.
4. **끌어서 여러 개 놓기와 칠하기**(3.1): 넓은 바닥과 벽을 하나씩 놓지 않게 합니다. 한 번에 묶어 되돌립니다.
